# NOTES — <Pallette Theme>

## Intent
The theme I chose for my style tile was "a cabin at dawn in a light snowstorm." I want it to set a wintery and nostalgic mood. This is for anyone wanting to know more about how these colors interact on a page. (It's also for me as well.)
## AI use
I used the free Copilot provided in VS Code. I gave it a prompt to create a new spark folder and a theme palette index.html, along with its own style sheet. I asked it to make a style tile with a specific theme of a cabin at dawn in a light snowstorm. I also provided it with the checklist to check my work and make sure I completed everything.
## Accepted / changed / rejected

I changed the ratios in the text and background contrast table because they weren't accurate. I kept the overall layout of the page because they worked well together (which I verified in the WebAIM contrast checker).

## Dig deeper
I dug deeper on "linear gradient" and learned that you are able to change the angle of the color by changing the degrees. When it was at 110 degrees, the pine color was in the top left corner. When I changed it to 0, it moved down and the lighter teal moved on top.
