# NOTES — <Color and Typography>

## Intent
The wildlife field guide is for people visiting the Pacific Northwest to learn about the wildlife in the area. It should feel straightfoward and informational while also giving a calm and natural vibe. The party invitation is for people attending a laser tag party to give them details about the party. It should feel electric, bright, and energizing. I built the homepage for poeple who will see the other two pages to give them an overview of my reasons for choosing the font and colors that I did.
## AI use
I used the free Copilot within VS Code for all three pages. For the field guide, I asked it for a field guide for marine wildlife in the Pacific Northwest area. I asked for a color palette, and a few different options for text, and I asked it to list several animals and basic information about them. I also gave it the done list to follow as a basic guidline for the layout.
For the laser tag invitation, I asked it to follow the requirements I asked it to follow for the marine field guide. I also asked it for another color palette and fonts that gave a laser tag vibe. 
For the homepage, I told the AI the purpose of the page, that it was to be a place for me to explain design choices and show the contrast results of the colors I used on each page, and I told it to follow a similar layout to my wildlife guide page. I told it to change the color palette to be different from the widlife guide page.
## Accepted / changed / rejected
For the field guide, I kept the color palette because I really loved it and the colors worked well together. The text color on each background color contrasted enough that it could be read and passed the WCAG AA test. But I changed one of the ratios slightly because the number was barely off. But the AI did a pretty good job with that this time; it only messed up one. The AI made a comparison table of different fonts on the page, and I rejected this because it wasn't really necessary to the page and it seemed confusing to look at. I ended up keeping the fonts for the laser tage invitation becuase I felt like they added to the theme really well. I changed a bit of the layout. I had to add the table about color contrast that the AI forgot to include. I rejected the descriptions on the color palettes for the home page because they looked cluttery, and I wanted to keep a cleaner look. I also changed the color palette that it gave me initially because it was teh same as the palette for the widlife guide. I changed some of the body text it gave me, specifically the sections about my font and color choices.

## Dig deeper
For my field guide page, I dug deeper on text-transform and learned that it helps you control capitalization of an element. You can change it to all uppercase, lowercase, or capitalize. https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-transform
One thing I looked up for the invitation was letter-spacing. It seemed pretty self-explantory just from the name, but I still wanted to learn more about it. I learned that it adds space between letters. Positive values add space, and negative values remove space. This can be used to make certain headings or labels stand out a bit more. https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/letter-spacing
For the homepage, I looked deeper into margin-block and learned that it sets the spacing of something on the page. https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/margin-block-start
